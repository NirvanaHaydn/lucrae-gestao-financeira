=======================================================================================================================
Estrutura do Projeto
lucrae-app
│
├── app
├── assets
├── css
├── data
├── js
└──public

=======================================================================================================================
PASTAS:

CSS:
Contém os arquivos de estilização da aplicação.


ASSETS:
Armazena recursos visuais utilizados na aplicação.
    Pode conter:
    imagens
    ícones
    logos
    ilustrações
    arquivos gráficos.


DATA:
Contém dados simulados (mock data) utilizados durante o desenvolvimento.


JS:
Contém toda a lógica JavaScript da aplicação.
Estrutura:
js
│
├── components
├── pages
├── services
│
├── main.js
└── router.js

=======================================================================================================================
ARQUIVOS:

index.html --> Página inicial do sistema interno da aplicação.

login.html --> Página de autenticação do usuário.

register.html --> Página para criação de uma nova conta.

about.html --> Página institucional com informações sobre o projeto e equipe.

news.html --> Página dedicada a notícias sobre economia e finanças.

education.html --> Página com conteúdos educativos sobre educação financeira.

dashboard.html --> Dashboard do usuário contendo:
                    resumo financeiro
                    saldo total
                    gráficos
                    visão geral das finanças

income-form.html --> Formulário utilizado para registrar entradas de dinheiro (salários, ganhos, investimentos etc).

expense-form.html --> Formulário utilizado para registrar despesas (contas, compras, gastos diversos).

analytics.html --> Página de análise financeira detalhada, contendo:
                        gráficos
                        tabelas
                        visualização mais profunda dos dados financeiros do usuário.
